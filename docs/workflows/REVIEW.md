# Review procedure

Read the task, diff, affected domain, tests, and CI results independently. Check negative cases, concurrency, permission boundaries, tenant access, input validation, migrations, compatibility, and sensitive governance changes where relevant. Check for tests that merely mirror the new implementation. Distinguish observed defects from hypotheses; give reproduction/evidence, severity, and file location. State residual risks if no findings. AI review does not substitute for domain ownership or required human review. Do not silently approve or merge your own changes.
